# EcoTrack • Carbon Footprint Awareness Platform

**Built for Hack2skill Main Challenge 3 — June 2026**

A fast, beautiful, privacy-first web application that helps people understand and reduce their daily carbon footprint with personalized, actionable insights.

## Key Features
- Interactive daily logger with smart presets (Chennai Weekday, Low Impact, High Footprint)
- Instant results with pie chart, breakdown, eco-score, comparison to Indian average (~5.2 kg/day)
- Dynamic personalized recommendations with estimated savings
- What-If simulator (switch to metro, reduce meat, cut AC)
- Full history + trend line chart + streak + 7-day avg (localStorage only)
- India & Chennai specific tips and grid factor
- 100% client-side, sovereign, no backend, works offline
